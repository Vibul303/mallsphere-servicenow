# 🏢 MallSphere – ServiceNow Mall Management System

MallSphere is an enterprise shopping mall operations and tenant service
management application developed on the ServiceNow platform.

The application centralizes tenant, store, lease, maintenance, vendor,
inspection, feedback, and lost-and-found operations into a single
ServiceNow solution.

## 🚀 Key Features

- Tenant Management
- Store Management
- Lease Management
- Maintenance Request Management
- Vendor Management
- Asset Inspection
- Visitor Feedback
- Lost & Found Management
- Role-Based Access Control
- Automated Maintenance Notifications
- Lease Expiry Reminder
- Reports and Management Dashboard

## ⚙️ ServiceNow Components Used

- Scoped Application
- Custom Tables
- Forms and Lists
- Application Modules
- Roles and ACLs
- Flow Designer
- Email Notifications
- Reports
- Dashboards
- ServiceNow Source Control

## 🔄 Automation

### Maintenance Email Flow
Automates maintenance request notifications and improves communication
between mall management and maintenance teams.

### Lease Expiry Reminder
Automatically identifies leases approaching their expiry date and
generates reminder notifications.

## 🔐 Security

MallSphere implements role-based access control using roles such as:

- Admin
- Manager
- Viewer
- Maintenance User

ACL rules are used to protect sensitive tenant, lease, and operational data.

## 📊 Reports & Dashboard

The MallSphere dashboard provides operational visibility through:

- Active Leases
- Leases by Status
- Tenants by Status
- Maintenance Requests by Status
